# Raw Dataset Directory

The raw dataset file (`household_power_consumption.txt`) is excluded from version control as it exceeds GitHub's 100 MB file size limit.

### Source
You can download the original Individual Household Electric Power Consumption dataset from the UCI Machine Learning Repository:
- **URL**: [UCI Machine Learning Repository - Individual Household Electric Power Consumption](https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption)

### Processed Dataset
The preprocessed and cleaned dataset used for training models and MySQL database imports is located in [`dataset/processed/energy_consumption_ml_dataset.csv`](../processed/energy_consumption_ml_dataset.csv) and is tracked in this repository.
